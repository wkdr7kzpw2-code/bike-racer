# iOS-cards karaoke video

Вертикальное видео 1080×1920, 30 fps: каждая строчка песни — своя iOS-карточка на тёмном
пастельном фоне, сверху караоке-подпись (слова подсвечиваются по мере пения), карточки
сменяются через размытие ровно в бит.

## Запуск

```bash
cp lyrics.example.txt lyrics.txt          # впиши свои строчки
python3 make_video.py --lyrics lyrics.txt --audio song.mp3 --start 42.5 -o video.mp4
```

- `--start` — с какой секунды песни начинать фрагмент.
- `--duration` — длина ролика (по умолчанию 15 с).
- `--bpm` — задать темп вручную, если автоопределение ошиблось (выводится в консоль).
- `--header` — подпись в шапке карточки (по умолчанию «Музыка»).
- `--demo` — демо с текстом-заглушкой и синтезированным битом.

Нужны только `python3` (numpy, Pillow) и `ffmpeg`; шрифт — Inter.
