# Moto Rush 🏍

2D-гонка на мотоциклах с трюками для Android.

- **Трюки:** бэкфлипы и фронтфлипы (комбо x2, x3…), вилли, долгие прыжки, чистое приземление.
- **6 трасс:** Зелёные холмы, Песчаные дюны, Красный каньон, Ночная трасса, Ледник, Вулкан —
  холмы, трамплины, пропасти, ступени. Каждая следующая открывается после прохождения предыдущей.
- **5 мотоциклов** (Скаут, Рейнджер, Шторм, Фантом, Дракон) с разной скоростью, разгоном и вращением.
  Покупаются за монеты, которые собираются на трассе и начисляются за очки.
- **Рейтинг:** таблица лучших заездов, рекорды по трассам, звёзды и звания игрока (от «Новичка» до «Легенды»).
- Главное меню, пауза, настройки (имя игрока, звук, вибрация), сохранение прогресса.

## Управление

| Кнопка | Действие |
| --- | --- |
| ▶ (справа) | газ |
| ◀ (справа) | тормоз / задний ход |
| ↺ ↻ (слева) | наклон назад / вперёд (в воздухе — сальто) |

На компьютере: стрелки или WASD, `P` — пауза, `R` — заново.

## Устройство проекта

- `app/src/main/assets/` — сама игра (HTML5 Canvas + JavaScript, без зависимостей):
  - `core.js` — физика мотоцикла (Verlet), генерация трасс, трюки, очки;
  - `main.js` — графика, меню, гараж, рейтинг, звук, управление;
  - `index.html`, `style.css` — интерфейс.
- `app/src/main/java/.../MainActivity.java` — Android-обёртка (полноэкранный WebView, альбомная ориентация,
  кнопка «Назад», вибрация).
- `tests/sim.test.js` — автопилот проезжает все трассы на самом слабом и самом сильном мотоцикле и проверяет,
  что сальто засчитывается: `node tests/sim.test.js`.

## Сборка APK

Нужны JDK 17+ и Android SDK (platform 34):

```bash
./gradlew assembleRelease
# APK: app/build/outputs/apk/release/app-release.apk
```

APK также собирается автоматически в GitHub Actions (вкладка **Actions → Build APK → Artifacts**).

Игру можно запустить и в браузере: откройте `app/src/main/assets/index.html`.
